智能客服 RAG Pipeline

离线阶段（构建知识库）

1. 收集文档 → 产品手册、FAQ、政策等
2. 清洗与切分 → 去除噪声，切分为 300~800 字的片段
3. 向量化 → 调用 Embedding 模型，将每个片段转为向量
4. 存入向量库 → 写入 Chroma / Milvus / FAISS

在线阶段（回答用户提问）

5. 用户提问 → 接收自然语言问题
6. 检索 → 将问题向量化，从知识库中召回 Top-K 个相关片段（可结合关键词检索）
7. 组装提示词 → 将检索到的片段 + 用户问题 + 系统约束拼成 Prompt
8. 大模型生成 → 调用 LLM API，输出答案
9. 返回结果 → 答案 + 引用来源，并记录日志

---

MVP 最简实现路径

```
产品文档.txt → 切分 → Embedding → Chroma
                                      ↓
用户问题 → 向量检索 → 拼接 Prompt → LLM → 回答
```

关键组件

· Embedding：通义 text-embedding-v2 / OpenAI
· 向量库：Chroma（开发）
· LLM：通义千问 / GPT-4o-mini
· 接口：FastAPI
